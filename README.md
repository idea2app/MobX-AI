# MobX-AI

AI SDK models and React components built with MobX.

[![Test & Publish][1]][2]

## Install

```sh
npm install pnpm -g
pnpm install
npm test
```

## Packages

- [`ai-sdk-mobx`][3] provides MobX models for AI SDK interactions.
- [`ai-ui-react`][4] provides React components for AI applications.
