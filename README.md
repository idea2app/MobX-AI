# MobX-AI

AI SDK models and React components built with MobX.

## Install

```sh
npm i pnpm -g
pnpm i
npm t
```

## Packages

- [`ai-sdk-mobx`][1] provides MobX models for AI SDK interactions.
- [`ai-ui-react`][2] provides React components for AI applications.
