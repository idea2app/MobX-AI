# AI UI for React

React components for AI applications, built with [`ai-sdk-mobx`][1], [`idea-react`][2], and [`mobx-restful-table`][3].

This package is being prepared; its public component API is not available yet.

## Install

```sh
npm install ai-ui-react
```

[2]: https://github.com/idea2app/Idea-React
